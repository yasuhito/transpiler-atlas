Interpretation

  • Quality combines 2Q count and 2Q depth. Scores use equal family weights and the dataset's Qiskit level 2 baseline of 100. In a mixed-source dataset this is the unchanged v0.4 reference, not a new L2 measurement.
  • Speed uses a 1 ms floor. Quality and Speed scores equal the unpenalized performance score multiplied by the QCEC pass rate. Asterisks and tinted cells mark pass-rate penalties. This is a benchmark rule, not a hardware success probability. Raw measurements remain visible; N/A means required measurements or reference values are unavailable.
  • Each row is one SDK/configuration pair. Level numbers are SDK-specific, not comparable effort units. pytket Basic and Peephole repeat the same unseeded pipeline; Pauli + peephole uses the scheduled seed. QMAP seed slots repeat an unseeded mapping-only pipeline; they are not mapper RNG seeds.
  • Timing includes pipeline construction and compilation. Parsing, export, conversion for validation, QCEC, and BQSKit local runtime startup/shutdown are excluded. QMAP's required IR-to-Qiskit conversion and native basis lowering are included.
  • No enforced memory cap, exclusive host, or CPU frequency control. A first-use cost can enter the first of three timing repetitions.
